## 💼 What I Do

I build real-world web projects by pairing a problem-solving mindset with AI tools. Focused on practical, client-ready solutions for small businesses, experts and local companies.

- 🖥 **Лендинги и сайты-визитки** — адаптивные страницы с формами заявок, которые приводят клиентов
- 🤖 **Чат-боты** — отвечают клиентам по базе знаний, принимают регистрации, напоминают о событиях
- 🧮 **Веб-инструменты и приложения** — калькуляторы стоимости, канбан-доски, трекеры задач

## 🛠 Стек

- **AI:** OpenCode · ChatGPT · DeepSeek · Qwen · Z.ai
- **Frontend:** HTML5 · CSS3 · JavaScript · Tailwind CSS · Alpine.js
- **Backend:** PHP 8.4 · Laravel 12 · Python · SQLite
- **Инфраструктура:** Git · GitHub · GitVerse · GitHub Pages

**Как я работаю:** анализ задачи 📋 → промпт-инжиниринг ✍️ → вайб-кодинг и отладка 🛠 → тестирование и сдача 🚀
